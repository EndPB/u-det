版本：v1.0（2026-10-12）  
性质：**平行新起点**的独立总账。本文件是 d-det-v2 线的唯一入口；与旧 d-det 的历史总账

## 0. 一句话定位

在"**旗舰模型 base 一致**"的强假设下，用**代码条件的后训练差异**表示，在既有全量数据上
**一次性快速验证 A（二分类）与 B（家族归因）** 相对同预算 CodeT5 完整微调基线的增量。
**只做 A/B；C 暂缓。**

- 卖点：Code-Conditioned Post-Training Differences（代码条件的后训练差异）。
- 首目标：快速、可证伪、全量——不是再做一轮数据闸门循环，也不是堆容量/温度/损失项。

## 1. 线级公理与定义（直接采纳，不再论证）

### P1（base 一致公理，强制）

**直接强行假设：旗舰模型之间的 base 行为差异忽略（ε≡0）。**  
跨来源观察到的一切代码条件差异，一律读作**后训练/运行差异**。本线不为其设置敏感性实验、
前置校验或收缩条款；实验设计与结果表述均按该公理进行。（该公理是本线的定义性选择。）

### D1（A = 后训练差异的二分类）

A 是 **Human vs Machine 的二分类**，但判别依据必须是**代码条件的后训练差异表示**：

- Human 视为**参考策略类**，Machine 表示后训练/运行策略来源；
- 输入只含待测代码（+可选任务条件），不要求同题参考样本；
- 验收 = 相对**同预算 CodeT5 完整微调基线**的预注册增量；
- 禁止把 A 写成通用"AI 文本检测"或多语言 OOD 卖点（那是已有工作）。

### D2（B = 含 Human 的家族归因）★ 重点

B 的标签空间 = **{Human} ∪ {family_1 … family_K}**。

> **核心规则：同一家族的多个生成器（成员）折叠为同一个家族标签。**

示例（家族边界以冻结的 `family_series_admission` 证据为准）：

| 家族标签 | 折叠的生成器（示例） |
|---|---|
| `CodeLlama` | 7B / 13B / 34B / 70B（*-Instruct-hf） |
| `Qwen2.5-Coder` | 1.5B / 7B / 14B / 32B |
| `DeepSeek-Coder` | 1.3B / 6.7B / 33B |
| `Human` | 真实人类代码（真实类，不是 AI 家族） |

要求与边界：

1. 每个源必须有自己的 `label_map` 与 provenance；不同源的标签空间不得直接拼接；
2. AI-only 的 source/generator 头仅作辅助诊断，**不能替代 B**；
3. 缺 provenance 时只写 task-heldout，不写 project-heldout；
4. 评估同时报告：**同族内未见成员（member-heldout）、未见家族（family-heldout）、Human 类 recall**；
5. 同族多生成器的现成证据主要来自公开系列包（11 成员：CL4/Q4/DS3）；STACAD 的 7 generator
   为跨厂商（`same_family_pairs=0`），用于 Human anchor 与跨族控制，**不能**用作族内迁移证据。

### 范围

**只关注 A、B。** C（四分类）不在本线范围；AICD 封存为外部数值控制，禁止训练。

## 2. 表示与模型（压缩自《主线重构讨论稿 v0.5》与《独立交接指导》，详情可回引）

### 2.1 核心对象

- 相对行为差异：`a_fg(c|t)`（来源 f vs g 在同任务/接口下的密度比判别）；
- 安全变换响应：`Δ_fg,T(c) = a_fg(c) − a_fg(T(c))`（T 需 CST/编译安全审计）；
- 没有谱系/配对时不伪造 `L_diff`；Human/AI 不命名为 post/reference（在 P1 下，均按后训练差异解读）。

### 2.2 结构与组件

- 语义流 `h` + 布局流 `l`（tab/space、空行、行尾空白、行长、换行、注释位置）；
- 任务中心化 `r_sem = h − μ_task`：训练期机制（测试期参考集合接口另行登记）；
- AMMC train-only 视图（comment .2 / whitespace .3 / rename .4；parent-child、标签继承、配平）；
  变体**不产生**新类别标签。

### 2.3 模型矩阵（一次批次、同预算）

| 配置 | 作用 |
|---|---|
| `codet5_full` | 同数据、窗口、预算、seed 的完整 CodeT5 微调基线（第一列） |
| `d-det_semantic` | 后训练差异表示 + 任务中心化读出 |
| `d-det_semantic_layout` | 加布局流（保留 layout-only 控制） |
| `d-det_semantic_ammc` | 加 train-only AMMC 视图与选择性一致性 |
| 控制 | lexical / format / metadata、source-label shuffled、label-shuffled 负控制 |

### 2.4 损失（AB-only，无 L_C）

```text
L = L_A + λ_B·L_B + λ_r·L_response + λ_v·L_selective-view + λ_h·L_hard
```

- `L_selective-view` 只作用于 A/控制头，**不强迫 B 抹掉真实 family style**；
- 读出必须同时报告 `z-only / a-only / joint` 三档。

## 3. 快速全量验证协议（本线第一目标）

- **口径**：直接使用既有全量入口——STACAD-v2 清洗全量（144,958 pair / 22,053 files / 7 语言）、
  公开同任务全量（296,254 行 / 1,539 task）、系列包（11 成员）。独立 parent/task/generator/family
  计数如实报告；不以增强行数冒充独立样本。
- **批次**：§2.3 矩阵一次执行；同 backbone、窗口、预算、折、seed；≥2 折 × ≥3 seed。
- **评测**：
  - A：row + task-macro、短/中/长切片、formatter/规范化 stress；
  - B：Human-inclusive macro-F1、每类 recall、member-heldout、family-heldout；
  - 控制读数（length/lexical/view/重复）随批报告，作为解释与收缩依据（如"仅原视图有效→来源探针"）。
- **判定**：相对同预算 CodeT5 的**预注册增量**；两折 × 多 seed 不同向或无增量 → 关闭分支。
- **停止规则**：不加容量、温度、轮数、损失项；不重跑已关闭旧包。
- **交付**：单一目录（`manifest` 全件 + `SHA256SUMS` + 日志 + env/git_head），一次回传。

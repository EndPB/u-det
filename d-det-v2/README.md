## 目的（只做 A/B）

1. **B｜F 家族归因**：输入一份代码 → `Human` 或某个 AI **家族**。多家族、家族下多生成器，**归因到家族级别、不归因到生成器级别**（generator 只用于折与分层）。
2. **A｜D 二分类检测**：输入一份代码 → Human/AI 概率；与归因同一方法形态，**基于代码条件的后训练差异**。

C（四分类）暂缓；AICD 封存（外部数值控制，禁训练）。

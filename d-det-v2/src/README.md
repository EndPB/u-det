# src（代码目录）

- **每个版本一个独立文件夹**：`src/v0.1/`、`src/v0.2/`……**从 v0.1 重新编号**（不沿用旧 d-det 版本号）。
- 每版**自含代码与配置**，保持**极简**：能一个文件解决的不拆两个，不做框架化设计。
- 版本在"该版首批批次启动/冻结"时确定；已冻结版本只读，改动开新版本。
- 产物不写在本目录，统一放 `d-det-v2/artifacts/`（注意：`runs/` 被仓库全局忽略，不要用）。
- 当前：`v0.1` = 实现《家族归因与二分类检测 设计及执行指导 2026-10-13》首批六臂矩阵；**尚未实现**。

# U-Det

## 想法

对于AI代码检测，暂只考虑二分类。参考 1D u-net，用下采样替代长上下文的滑动窗口，实现极长上下文甚至可理论拓展到无限的长度处理；在 u-net 的中间即最底部接上样本级分类；上采样和跳跃连接回来的时候做token级分类。

为便于消融实验和改进，模块必须支持插拔。使用 codet-m4 的 1/10 用于小规模实验。编码器使用 codet5。代码必须极简。

上采样的时候对应不同的文本长度精度，每层计算损失，通过跳跃连接来引导下/上采样。

样本级和 token 级两个任务一起端到端训练。

为添加信息，在代码前注入短报告，包括：

1. 结构偏置：空行率 R_void = 空行数/总行数；缩进一致性；行末尾空行
2. 词汇可预测性：字符、二元组香农熵
3. 句法方差：命名惯例方差、行长方差

# d-det E25 服务端指导文档：旗舰来源的判别式密度比与 E24 复核

版本：2026-09-29。可独立转交与执行；基于 EndPB/u-det 提交 90d10f1，以 d-det/scripts/flagship_round1.py、flagship_r1_diag.py 和 E24 交接报告为实施依据。本文列出的是**下一轮方案**，不是已验证结果。无需重新生成代码样本；新训练臂最多 2 epoch。

## 1. 核心问题与理论边界

给定任务或提示 \(t\)、代码 \(x\)、已见生成家族 \(f\in\mathcal F\)（E24 中 \(|\mathcal F|=8\)），目标是分别估计 AI–Human 检测与 AI 条件下的家族归因。允许利用不同现成模型的代码产物；不把 base/instruct 对作为主数据。

作为**理想化的后训练机制**，若固定参考生成分布 \(p_{0,f}\)，并通过 KL 正则奖励优化得到家族 \(f\) 的分布，则
\[
p_f(x\mid t)=\frac{p_{0,f}(x\mid t)\exp[r_f(x,t)/\beta_f]}{Z_f(t)}.
\]
从而对同一个 \(x,t\)：
\[
\log\frac{p_f(x\mid t)}{p_g(x\mid t)}
=\log\frac{p_{0,f}(x\mid t)}{p_{0,g}(x\mid t)}
+\frac{r_f(x,t)}{\beta_f}-\frac{r_g(x,t)}{\beta_g}
-\log\frac{Z_f(t)}{Z_g(t)}.
\]
这是**在上述假设下的代数恒等式**，不代表所有旗舰模型真的由相同的 KL 目标训练，也不能仅凭最终代码识别奖励项。预训练、架构、提示、采样和数据来源可能混入观察到的家族差异。论文中只能称“后训练相关的生成来源差异”及其工作假说，不称“识别出纯后训练因果效应”。

定义 \(P_H(x\mid t)\) 为 Human 分布，\(P_{AI}(x\mid t)=\sum_f\pi_{f\mid AI}P_f(x\mid t)\)。在共同支持集上，下面的**密度比恒等式**给出了两个任务的联系：
\[
\log\frac{P_f(x\mid t)}{P_H(x\mid t)}
=
\underbrace{\log\frac{P_{AI}(x\mid t)}{P_H(x\mid t)}}_{\ell_D^*(x,t)}
+
\underbrace{\log\frac{P_f(x\mid t)}{P_{AI}(x\mid t)}}_{\ell_F^*(f,x,t)}.
\]
这是分布层面的分解；不能推出表示空间必有 \(z=\mu_t+\delta_{AI}+\rho_f+\epsilon\)，也不能推出去除一个“AI 方向”会改善归因。学习 \(z=\Phi(x)\) 后，在**表示空间**重新定义 \(P_c(z\mid t)\) 并估计相应密度比；编码器丢失的信息无法凭这个恒等式恢复。E24 缺乏可信 task_id，只能估计边缘量 \(P_c(z)\)，不能声称已控制任务 \(t\)。

DCAN 借鉴点是区分语义与来源线索；其实际研究的是来源无关语义与来源特定风格的分离，不能当成本方法“检测/归因天然正交”的证明。DMHM 借鉴点是密度感知流形；E24 的对角高斯加体积项不是 DMHM 的完整局部/全局混合度量。两者均列为相关方法，不把重现其框架设为 E25 主任务。参考：[DCAN 原文](https://arxiv.org/abs/2603.04212)、[DMHM 原文](https://aclanthology.org/2026.acl-long.180/)。

## 2. 已知证据与必须修复的实现问题

E24 采用冻结的 CodeT5 编码器、2 epoch 训练。\(z=[\mu;\log(v+\varepsilon);s_{\mathrm{top}}]\in\mathbb R^{1537}\)，其中 \(\mu,v\in\mathbb R^{768}\)、\(s_{\mathrm{top}}\in\mathbb R\)。下列为**实际测得值**：

| 方法与指标 | val | test_seen（已见家族的新模型） |
|---|---:|---:|
| M0 raw mean 逻辑回归检测 AUROC | .9571 | .9721 |
| E24 能量检测 AUROC | .9147 | .9243 |
| M0 raw mean DiscHead 家族 acc / bal | .4158 / .4225 | .3304 / .2773 |
| E24 raw \(z\) 家族能量 acc / bal | .2327 / .2412 | .1607 / .1815 |
| E24 残差家族能量 acc / bal | .2353 / .2456 | .1339 / .1729 |

另外，同一 \(z\) 的验证集 DiscHead 为 **.4042 / .4109**；同一残差 \(r_F\) 的 DiscHead 为 **.3915 / .3981**。这支持“当前能量读出较弱”的诊断，但并不证明家族完全服从线性边界。E24 固定上下文向量后置换 token 行的 maxdiff=7.6e-06；用户提供的 results.json 中 4.7907 与之冲突，后者可能混入原始 token 重排。**保留 E24 原件，在 E25 诊断中同时记录两种测试的输入层级、数值与文件哈希**，不覆盖历史结果。

先修复以下评分一致性错误，再谈 F1 或校准：

- 训练脚本 tensor_pack() 设 logpi_f=log(st["pi"][1:])，它是全局先验 \(\pi_f=P(f)\)；训练检测的 log_ratio=log(pi_AI/pi_H) 又额外加入了 \(\pi_{AI}\)。评估 s_d_scalar() 则先规范化为条件家族先验 \(\pi_{f\mid AI}=\pi_f/\pi_{AI}\) 后只加入一次 log_ratio。两者相差固定的 \(\log\pi_{AI}\approx\log(9600/17600)=-0.606\)（此值按 E24 裁样计算），影响检测阈值与 F1，**不改变同一模型 AUROC 的排序**。
- 修法：训练、验证、测试统一计算
  \[
  G_{AI}^{(T)}(z)=-\log\sum_f\pi_{f\mid AI}e^{-G_f(z)/T_E},\quad
  s_D^{(E)}=\frac{G_H(z)}{T_E}-G_{AI}^{(T)}(z)+\log\frac{\pi_{AI}}{\pi_H}+b_D.
  \]
  代码中用 logpi_f=log(pi[1:]/pi[1:].sum())，检测比值只加一次；家族 softmax 的共同常数会抵消。
- \(T_E=1537\) 是 E24 能量尺度的操作定义，不能再把 \(G/T_E\) 解释成未经改变的高斯负对数密度；可称“温度化流形分数”。第一轮复核固定 \(T_E\)，不在 test 上调节。
- rejection_auc_maxp=.588 若以 unseen 为正类、maxp 为分数，衡量的是“越有信心越未知”，**不是正确方向的拒识 AUC**。请同时保存 AUROC(unseen, -maxp)（在完全相同样本和无权重设置下应约为 .412）及原分数；拒识能力不能由 .588 正向表述。

## 3. E25 最小方法与维度

保留 E24 的冻结编码器和 SetPool，确保新特征试验与 M0 使用完全相同的样本、编码器与裁样。令一条代码的有效 token 数为 \(L\)：
\[
H(x)\in\mathbb R^{L\times768}
\ \xrightarrow{\text{共享 token MLP + 集合统计}}\
z(x)\in\mathbb R^{1537}.
\]
令训练集均值与标准差为 \(m,\sigma\in\mathbb R^{1537}\)，\(\bar z=(z-m)\oslash\max(\sigma,\varepsilon)\in\mathbb R^{1537}\)。标准化量**只用训练折拟合**，val/test 固定；E25 端到端训练时，在初始化头后用训练折估计一次并固定 2 epoch，避免每批用当前样本更新统计量。

**默认检测头（单标量）**
\[
s_D^{\mathrm{disc}}(x)=w_D^\top\bar z+b_D,\quad
w_D\in\mathbb R^{1537},\ b_D\in\mathbb R,\quad
p_D=\sigma(s_D^{\mathrm{disc}}),\quad
\mathcal L_D=\operatorname{BCEWithLogits}(s_D^{\mathrm{disc}},y).
\]
在正确先验实现下保留上面的能量 \(s_D^{(E)}\) 作**同特征对照**，不把它预设为主检测头。

**默认家族头（8 类、全维判别）**只对真实 AI 样本训练：
\[
a_F=W_F\bar z+b_F\in\mathbb R^8,\quad
W_F\in\mathbb R^{8\times1537},\quad b_F\in\mathbb R^8,
\]
\[
p_F(f\mid AI,z)=\operatorname{softmax}(a_F)_f,\qquad
\mathcal L_F=\operatorname{CE}(a_F,f).
\]
它是判别式**后验估计**。只有在训练采样先验等于声明的部署先验、优化与校准充分时，logit 差才可解释为对应的对数密度比；不能称逐一恢复真实奖励或真实生成似然。无需额外“低秩归因空间”。已有 DiscHead（LDA 输出最多 7 维）可作为**离线对照**，其降维由 8 类判别解固有产生，不能把它宣称为证明预设低秩必要的证据。

**本轮训练目标**
\[
\mathcal L=\mathcal L_D+\mathcal L_F
\]
其中 \(\mathcal L_F\) 在 AI 子批内取均值，\(\mathcal L_D\) 在全批内取均值；记录两者各自有效样本数。E24 的 SupCon、\(r_F=z-\mu_H-\alpha(z)\delta\) 与 token 损失本轮默认关闭。残差 \(r_F\in\mathbb R^{1537}\) 仅作固定特征消融，避免同时改变头与损失而无法归因结果。若后来有可靠 task_id，再设计按题目条件的困难正负例；不能用“同语言”冒充“同题”。

## 4. 执行次序与对照

**阶段 0：不训练新编码头，仅复核与离线探针。**

1. 用提交 90d10f1 的 E24 head.pt、stats.npz 和现成代码重新导出相同顺序的 train/val/test_seen/unseen 特征；保存样本 ID、split、generator、family、language、长度与 z/raw_mean 的索引映射。
2. 修复训练/评估先验不一致并计算正确方向的拒识 AUC；单独重新跑固定 \(H\) token 行置换检查。将修复后检测 F1 作为诊断，不篡改旧 results.json。
3. 在 **同一批** E24 特征上拟合训练折标准化 + 固定正则的检测逻辑回归和 8 类家族线性 softmax / DiscHead。并列比较 raw mean、\(\mu\)（前 768 维）、\(z\)（1537 维）、\(r_F\)（1537 维）。M0 用同样划分重新计算；阶段 0 的选择只看 val，test_seen/unseen 的批量评分留到阶段 1 结束后统一执行。此阶段不动编码器，不需要 GPU 训练。
4. 检查样本原文或已存代码可用时，对 train/val/test 作规范化代码精确去重与近重复审计；若仅有 ids，则先对 ids 做精确去重并记录其局限。输出各家族**实际 generator 列表与样本数**：SemEval-B 的 8 个实验室家族不能整体等同为“8 个旗舰模型”。在现有数据中另列确属强/旗舰模型的子集及样本量；若样本不足，就把主结果如实称作“跨实验室来源”，不冠以“跨旗舰模型”。没有任务键时，不声称按题目分组不泄漏。

**阶段 1：仅当阶段 0 的判别式 \(z\) 在 val 的家族 balanced accuracy 至少不劣于 raw mean M0，才运行单个新训练臂。** 从 E24 相同冻结编码器与固定随机种子初始化新 SetPool，以 \(\mathcal L_D+\mathcal L_F\) 训练 2 epoch；不得复用已经用 E24 能量损失训练过的头作为“从零比较”起点。每个 epoch 保存训练损失与冻结特征上的 val 指标；用预定规则（家族 val balanced accuracy 为主、检测 val AUROC 为并列报告）挑 epoch，**test_seen 和 unseen 只最后评估一次**。如果阶段 0 没有越过 M0，则暂停阶段 1，先调查 family/generator 混杂与表示信号，不通过增加损失项掩盖负结果。

| 对照 | 特征与读出 | 训练成本 | 用途 |
|---|---|---:|---|
| B0 | raw mean 768 + logistic / DiscHead | 离线 | E24 M0 精确重算 |
| B1 | E24 的 \(z\) 1537 + logistic / 线性 softmax | 离线 | 固定特征验证判别规则 |
| B2 | E24 的 \(z\) 1537 + 已修复先验的温度能量 | 离线 | 同特征能量对照 |
| B3 | E24 的 \(r_F\) 1537 + 与 B1 相同的家族头 | 离线 | 检验 \(\delta\) 投影是否损失家族信息 |
| E25 | 新训练 SetPool + 联合判别头 | 最多 2 epoch | 检验表示是否可由两个任务共同改进 |

不要把 B1/B2 的“固定 E24 头”与 E25 的“重新训练头”直接解读为只改变决策规则的严格消融；严格同特征比较在 B0–B3 内完成。M0 的检测和归因在 unseen 家族上的适用口径不同：**未见家族只能测二分类检测和拒识，不能计入已见 8 类 closed-set 准确率。**

## 5. 必交报告、通过条件与项目边界

报告应包含：完整样本与 generator 清单；训练/验证/test_seen/unseen 的去重交集；各类标准化与先验；训练与推断的相同输入下 s_D 差异（预期误差接近浮点精度）；固定 \(H\) 行置换 maxdiff；B0–B3 和 E25 的 val/test_seen 检测 AUROC、macro-F1（阈值仅在训练或 val 决定）与家族 acc、balanced accuracy；unseen 对 Human 检测 AUROC（补 M0）和方向正确的拒识 AUROC；按家族、generator、语言、长度桶的数量与指标；种子、运行时间、参数量。E24 的 unseen 池由训练、验证和测试三个来源的**留出家族**样本拼接，比较时必须保留每条样本的原始 split，报告总体值和各 split 值，并说明 Human 对照来自 val。test_seen 家族数量很不均衡（如 Mistral/IBM 各 18），给出每族召回及不确定性，不以单一小数宣称微弱提升。

**阶段性通过条件**：E25 至少在 test_seen 的检测 AUROC 和家族 balanced accuracy 上分别不劣于 B0；留出家族 AI 检测不能只在已见家族改进后明显恶化。只有满足这些条件、重复种子保持方向一致，才将其作为论文主候选；否则保留 B0，并写明能量/残差负结果。拒识新方法另起实验，不把阈值校准冒充学习到的未知家族表示。

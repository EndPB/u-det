   修正后 **μ −0.67pt / μ+log v −1.07pt**，仍未过门控。原「反稀释」措辞已改为「未达 raw-mean」。
3. **C｜unseen 计数更正**：**train 1200 / val 945 / test 64（总 2209）**；E25 报告初稿的「971/38」为笔误

4. **D｜旗舰子集固化**（标准写死脚本、18 generators）：train **4013** / val **1654** / test_seen **342** /

## 1. A｜s_top 零梯度验证（方法 + 证据 + 机理）

**方法**（`scripts/flagship_e26_prediag.py` §A）：
1. 载入 E24 头部 `runs/flagship_r1/head.pt`，读取 `wq.weight` 范数与 `wq.bias`；
2. 读取 `runs/flagship_e25/features.npz` 中 z 的末维（s_top）在 train/val 上的分布；
3. 复现 E24 全损失（L_D + L_F + L_CD + L_CF，权重同 E24）于**固定 batch**（seed=0 的 64 条 train），
   v1.0 编码器 bf16 前向、冻结统计（stats.npz），一次 `loss.backward()` 检查各参数梯度。

**证据**：

| 检查项 | 结果 |
|---|---|
| `wq.weight` 范数 / `wq.bias` | **0.0 / 0.0** |
| s_top（train / val） | min = max = std = **0** |
| 训练统计末维（9 类） | μ_c = **0**、ṽ_c = ε = **1e-6**、δ = **0**、家族残差 μ = **0** |
| wq 梯度（weight / bias） | **0.0 / 0.0** |
| 对照梯度 | W1.weight **.871**、W2.weight **.339**、bD **.033** |
| 损失 | total **3.5222**（L_D .288 / L_F 1.986 / L_CD 3.897 / L_CF 8.592），finite ✓ |

**机理（双重退化，为什么梯度恰为 0）**：
1. `wq` 为零初始化（权重+偏置同零）⇒ q_i ≡ 0（与输入无关）⇒ s_top ≡ 0；
2. s_top 恒 0 使冻结统计对该维对称：能量项 ∂G/∂z₁₅₃₆ 在 (z=0, μ_c=0) 处为 0；
   rF 的残差方向 δ 在该维为 0；SupCon^D/F 对所有样本 e₁₅₃₆≡0（rF₁₅₃₆≡0），
   故对 e₁₅₃₆ 的导数也为 0。
   ⇒ **原点是不动点：只要训练从零开始，wq 永远不会离开原点**（并非简单的"没学好"）。

**结论与限界**：
- 全部涉及 s_top 的解释（例如"s_top 无检测信息""关键 token 证据不成立"）**撤回**；
  正确表述是「该分量从未被训练」。
- E24/E25 的表示结论范围限定为「**μ + log v 的现有表示实验**」。
- s_top 的独立价值需要**非零起点 + 预定尺度**的单变量实验才能判断（建议见 §8-2）：
  注意冻结统计中该维 v=ε=1e-6，标准化会放大约 1e6 倍——实验前必须先修尺度（否则必炸）。

## 2. B｜正则网格（μ vs raw mean vs μ+log v）

**方法**：train 折拟合、val 选择（test_seen 未读取）；特征标准化（Scaler 只 fit AI-train）；
`LogisticRegression(max_iter=2000, C∈{0.01,0.03,0.1,0.3,1,3,10})`；指标 = val 家族 balanced accuracy。
注：features 中 z ≡ μ+log v（末维恒 0），故网格只列三项。

| C | raw mean acc/bal | μ acc/bal | μ+log v acc/bal |
|---:|---|---|---|
| 0.01 | .4197 / .4262 | .3905 / .3979 | .4011 / .4092 |
| **0.03** | **.4215 / .4280** ★ | .4055 / .4125 | **.4032 / .4106** ★ |
| 0.1 | .4109 / .4171 | **.4145 / .4213** ★ | .3902 / .3970 |
| 0.3 | .4019 / .4077 | .4096 / .4165 | .3778 / .3842 |
| 1 | .3913 / .3968 | .4073 / .4139 | .3662 / .3721 |
| 3 | .3858 / .3913 | .4021 / .4089 | .3564 / .3619 |
| 10 | .3838 / .3893 | .3982 / .4050 | .3476 / .3534 |

**读数（修正后）**：
- 三者最优正则**不同**：raw best @C=.03、μ best @C=.1——E25 报告在 C=1 单点上比较（μ −0.86pt、
  μ+log v −1.16pt）低估了 μ；**匹配正则后：μ −0.67pt、μ+log v −1.07pt**，均仍未达 raw mean。
- 网格**形状**本身是信息：μ 的曲线随 C 单调缓降（.3979→.4213→.4050），raw mean 峰更靠左、下降更快
  （过拟合更强）；μ+log v 全网格低于两者。
- 结论边界（写入 E25 勘误）：**不得**据此判断二阶（log v）信息本质无用——头部从未以 μ+log v 联合训练过，
  线性探针只是下界；可说的是「匹配正则后 μ+log v 未超 μ，也无超 raw-mean 迹象」。

## 5. E｜ids→源码恢复 + 近重复审计（E25 遗留限制解除）

**方法**（`scripts/flagship_e26_dedup.py`，2.5 min）：
1. **恢复**：三个原始 parquet（b_train 50 万 / b_val 10 万 / b_test 1K 行）全量重分词
   （CodeT5 `add_special_tokens=False`；>1024 → ids[:768]+ids[-256:]），ids-md5 哈希匹配回采样样本（并按 split 校验）；
2. **审计**：标识符 5-gram MinHash（64 签名、16×4 LSH 分带）候选对 + 真实 Jaccard ≥0.7 验证；
   另做去空白归一化精确重复组。

**结果**：

| 项 | 值 |
|---|---|
| 源码恢复覆盖率 | train **17600/17600**、val **5372/5372**、test_seen **922/922**、unseen **2209/2209（100%）** |
| 源端命中 | train 18800（=17600+1200 unseen）、val 6317（=5372+945）、test 986（=922+64） |
| 近重复对（J≥0.7） | **train↔train 8**、**train↔val 3**；train↔test、val↔test、unseen↔\* 均 **0** |
| 近重复样例 | J .966/.762（DeepSeek-R1↔DeepSeek-R1 train↔val）、.785（Human↔DeepSeek-R1 train↔train）、.739/.745（同 generator 内部） |
| 精确重复组（去空白） | train **4 组**（JSON 存前 3 组：1 组 Human↔DeepSeek-V3 同码、2 组 DeepSeek-R1 内部） |

**判读**：
- 规模 ≤ 0.05%（11 对 / 26103 样本）⇒ 不影响 E24/E25 任何结论；
- **test_seen/unseen 与训练集 0 近重复** ⇒ 终评数字不受泄漏污染（此前的"无法审计"限制解除）；
- 两条数据质量线索（仅记录）：① 源数据存在「同码不同标签」（Human 与 DeepSeek-V3 各 1 行同码）——标签噪声，
  占比极小；② DeepSeek-R1 的重复集中出现（train 内部与 train↔val），与该 generator 的采样方式可能相关。
- "按题目分组不泄漏"仍**不声称**（数据无 task_id），此限制不因本审计改变。

## 6. 汇总：两项发现的联合含义

- **E25 门控 FAIL 原因细化**：不是"判别式路线失败"，而是「**μ+log v 表示（在给定训练样本与线性探针下）

  而判别式>能量的诊断（E24 +17pt）不受影响。
- **两条"负结果"的解释边界已收紧**：s_top 相关推断撤回；rF 只保留"经验负结果"（在 rF 上重新拟合逻辑
  回归 AUROC .5503——E25 报告已改口径）。
- **纪律不变**：门控未过 ⇒ 阶段 1 不启动；主候选保持 B0。上述诊断均为"不训练"可得的证据。

# d-det 旗舰域阶段 B 报告：固定主轴的来源残差（StageB）

> 规范来源：`docx/d-det_ACL主线与阶段路径_2026-09-30.md` §6 阶段 B（基线提交 `48e607a`）。
> 产物：`artifacts/flagship_stageb/{config,manifest,metrics,predictions.npz,train.log,stage_a_audit.json}`。

## 一句话结论

在固定 B0 主轴 + 门控来源残差的受控设定下，**同家族 SupCon 对来源残差的增量在两种门控实现下均 <1pt**（字面 η0=0：Δ01=+0.08pt；门控修正 W_R 零初始化 + η0=0.5：Δ01g=+0.29pt），且残差支路整体未超过 B0（字面臂持平、修正臂略低）→ **未达到触发阶段 C 的标准**；按文档暂停清单，不调 τ、不加几何变体、不启动跨 generator 关系集实验。

## 2 阶段 B 设计与预注册

- 主模型（文档公式逐字实现）：ℓ₀(a)=W₀a+b₀ **全程冻结**；r(a)=V·GELU(Ua+b₁)+b₂；ℓ_F(a)=ℓ₀(a)+γ·W_R·r(a)；γ=0.1·tanh(η)。
- 数据/协议沿用 E31–E33：五模型控制集（AI 4013/1654）、E28 冻结特征（sha256 `d83f63f6…`）、原 train-val 切分、逐字节相同批调度（64 批，正对 同gen 111063/跨gen 15913，empty_P=0）、批 128、AdamW lr 1e-3 / wd 1e-4 / clip 1、2 epoch、检测头冻结（val AUROC .9731）、**不读 test/unseen**。
- 臂：E0（残差 CE）、E1（E0 同初始状态 + 0.1·同家族 SupCon，τ=.1，作用于 r）、E2（冻结 γ=0 实现审计，η 不参与梯度）。
- 预注册判读：以 E1−E0（BA_F）为准，**≥1pt → 阶段 C 触发候选**；<1pt → 无实用增量。
- **门控修正的实施审计（预注册于 `config.json`）**：冒烟发现字面 η0=0 ⇒ γ≡0 ⇒ ∂ℓ_F/∂(U,V,W_R)=γ·…=0，残差分支 CE 梯度恒为零（"死门"，η 仅以噪声级漂移）。故增设 **E0g/E1g**：W_R 零初始化 + η0=0.5（γ≈0.046）——**初始贡献逐位为零（ℓ_F≡ℓ₀）且梯度全活**；其余完全不变。判读基准规则：若字面臂未点火（|γ|<5e-3 且参与度<1%），以 E1g−E0g 判读；两种实现全部如实报告（见 §5 诚实性）。

## 3 结果

**E2 实现审计（关键健全性）**：ℓ_F≡ℓ₀ ⇒ 与 B0 的 logits max|Δ|=**0.00e+00**，BA_F/BA_G 完全相同，γ 冻结为 0 —— 冻结主轴通路逐位正确。

**字面臂（E0/E1）**：门控按字面公式几乎不开（γ≈1e-4~6e-4，η 仅漂移 6e-3）。E0 的参与度比例 1.25% 系残差表示尺度膨胀所致；功能上与 B0 几乎无差别：E1 仅 1/1654 翻转，E0 10/1654，净差值 +0.08pt。E0↔E1 参数最大元素差：U 0.067 / V 0.050 / W_R 0.039。

**门控修正臂（E0g/E1g）**：γ 全程稳定在 .042–.046（η 从 0.5 起），初始批 CE 与 E0/E1 相同（=0.6077，即 B0 批 CE）；训练后残差功能幅度 3–6%，净翻转 20–28/1654。E0g 使 BA_F 降 0.47pt；E1g 把它拉回大半（Δ01g=+0.29pt），但两者均低于 B0。

**Δ01g 的家族构成**（E1g−E0g）：Mistral +0.30pt（Devstral-Small-2505 +2.1pt，Mistral-7B-v0.3 +0.33pt）、OpenAI +0.8pt、DeepSeek −0.25pt、Google −0.39pt —— 家族异质，主要来自单 generator 子集，未见跨族一致的增量。

## 4 判读（预注册规则应用）

1. **Δ01=+0.08pt（字面）/ Δ01g=+0.29pt（修正）均 <1pt → 无实用增量；阶段 C 不启动。** 即便取较大的修正臂差值，也达不到文档"稳定增量"的门槛（该差值 28 次翻转、家族异质、单种子）。
2. **残差支路未超过 B0**：字面臂持平（±0.05pt 内），修正臂 −0.18~−0.47pt。受控残差在既定 2-epoch 协议下没有可用的正贡献——这与 E31/E32/E33 的链条一致（容量/优化受控后来源模块无增量；E31 同容量 Δ=+0.11pt，本轮 +0.08~+0.29pt，量级相同）。
3. **机制读法**：冻结主轴的"受控"部分按设计实现（E2 逐位、E0g 起始与 B0 同分）；"增量"部分不成立。SupCon 对残差表示 r 的塑形（L_C 从 6.9 → 4.8）没有转化为边界改善；E0g 的退化说明残差支路在 CE 下学着放大/扭曲少量样本的 logit 而不带来净收益。
4. **不采取的动作**（文档 §7）：不调 τ、不加 SupCon 变体、不引入局部流形/正交惩罚/对角高斯/低秩空间、不做任务联合训练；不切换到 E30 generator 关系集。

## 5 边界与诚实性声明

- **门控修正臂的引入时点**：冒烟（全量前）发现字面规范死门后加入；规则与理由预先写入 `config.json`，两种实现全部报告，结论在两种实现下一致（这一点使阴性结论对门控实现选择稳健）。
- 单种子（种子 0）仅作候选证据；BA_F 差值 <1pt 的置信区间未做自助统计（与 E31–E33 协议一致）。
- 跨 gen 正对仅来自 Mistral（15913/127k 对），阶段 B 本身不依赖跨 gen 正对（SupCon 只用同家族正对）。
- 合成来源（六族）不能作为真实作者证据；五模型控制集的结论不外推到检测/AI 文本域之外。
- E0 的"已点火"自动标记由参与度比例触发，但该比例受 r 尺度膨胀影响；报告以两种实现的差值共同佐证阴性结论，不依赖单侧阈值选择。

## 7 与主线的关系（H1 证据状态）

- H1"受控来源增量"在强模型控制集上的本轮证据：**阴性（两种门控实现同结论）**。
- 与 E28（公平读出 Δ_F=−1.05pt）→ E30（弱跨生成器信号）→ E31（同容量 +0.11pt）→ E32（瓶颈=优化预算）→ E33（暖启动被可训练漂移摧毁）连成一条一致链条：**来源几何的可读出性成立；"在受控协议内训练一个来源模块带来实用增量"不成立**。
- 按文档要求：当前不自行启动阶段 C；等待外部指导决定主线是转向"数据构型/来源几何描述性证据"还是修改阶段 B 的训练预算/优化器设定后重试。

## 2. 实验 B：角色未知残差（`role_blind_residual_2026-10-08/`）

### 2.1 接口审计（先跑，全过）

- 交换不变性：**C_sym 相同 ✓ / S 相同 ✓ / A 变号 ✓ / R 相同 ✓**（300 单元数值断言，`interface_audit.json`）；
- 角色名无依赖（结构声明）；fit-only 标准化**实际应用**（纠正此前的“算过统计量未使用”）；
- fit-only OOF cross-fit（5 折，Ridge α=1.0）产生训练残差；eval 用 fit 全体系数；[0;A] 匹配容量臂。

### 2.2 结果（3 seeds；twin MLP）

| 变体 | task_dev M_b [CI95] | model 5 折均值 |
|---|---|---|
| A_only | 0.9767 [0.972,0.981] | 0.9705 |
| [0;A]（匹配容量） | 0.9750 [0.969,0.980] | 0.9697 |
| SA_full（raw S+A） | **0.9990 [0.998,0.999]** | **0.9988** |
| **role-blind R+A** | 0.9742 [0.967,0.980] | 0.9669 |
| oracle（C_instruct 残差+A，上界） | 0.9939 [0.991,0.996] | 0.9926 |
| R_shuffle | 0.9569 [0.948,0.965] | 0.9427 |

- **Δ(roleblind − A_only) = −0.25pt（task）/ −0.36pt（model 均值；5 折 −0.84~+0.30）**；
  **Δ(roleblind − [0;A]) = −0.09pt / −0.28pt**；**Δ(roleblind − oracle) = −1.97pt / −2.57pt**；Δ(roleblind − shuffle)=+1.73/+2.42pt。
- **判词（§3）：role-blind 增量消失 → 归档为 role-assisted / oracle-conditioned phenomenon。**
- **附加修正发现**：标准化基准下 **raw S+A（对称、无角色信息）最强（0.999）**——旧“残差化增益”在更好优化+角色未知接口下**不复现**；协议方向的可辨信号一部分本就寄居于表面可解释成分（被残差化扣掉后掉落）。旧 S_resid 结论（0.9683）应重述为“oracle 角色条件 + 未标准化基准上的现象”。

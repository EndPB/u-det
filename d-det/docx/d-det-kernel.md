## 1. 问题的来源（设计文档的四个悬案）

1. **免标注原理**（§3）：$s_2 \approx \log p_i/p_b$——从未被直接测量过（我们只有 hinge 代理）；
2. **归因能力**（注记 1）：$s_2$ 低秩子空间做家族归因——秩扫描证明需监督，但"归因的正确形态"未定义；
3. **法向/切向几何**（§2/§4）：$s_1$=离 base 流形距离、$s_2$=沿偏好方向位移——从未验证；
4. **跨实验室稳定**（§6）：偏好结构跨实验室稳定——从未验证。

E 系列针对这四个悬案设计，全部用**本地已有模型对**（Qwen0.5B/1.5B、DS-1.3B 的 base/instruct）直接计算真实量 $r^*$，避免"用代理验证代理"。

## 3. 实验详述

### 3.1 E1：真实 $r^*$ 的存在性（悬案 1 的第一刀）

**设计**：B val 分层 198 条（11 类 × 18），对每样本用 Qwen2.5-Coder-1.5B 的 base/instruct 两个模型做教师强制打分，
$r^*=\log p_i(x)-\log p_b(x)$（total 与 per-token mean 两版）。

**结果**：
- **免训练检测**：$r^*$ 的人机 AUC **0.81**（mean 版 0.72）；对照 s1 0.73、s2 0.30（反）；
- **三分组单调**：人 −22.5 ± 13.9 → base 机 −13.6 ± 14.9 → instruct 机 −4.8 ± 11.5（ANOVA F=20.5, **p=8e-9**）
  ——"被偏好调教的程度"在 $r^*$ 上单调有序：**§3 的位移量是真实可测的行为量**；
- **族间结构**：30 族 Kruskal H=41.9（p=0.003），族均值跨度 −36.9 ~ +5.0；
- **与我们的 s2 反号**：corr(r\*, s2_v1.0) = −0.25。

### 3.2 E2：换损失/换监督能救 s2 吗

**设计**：pairs 冻结特征（CodeT5 v1.0 mean-pool）上训练线性读出，2×2 对照：hinge vs Bradley-Terry logistic × 0.5B 配对 vs 1.5B 配对。评估：dir_acc + 在 E1 的 198 条上与 $r^*$ 的相关。

**结果**：dir_acc 全部 1.0；**corr(r\*, s2′) = −0.229/−0.230/−0.229/−0.230（四组几乎相同）**。
**结论**：对级目标（每对都要满足）的最优解就是位移的公共主方向——与损失形式、监督代际无关。⇒ 学习失败是**目标设计**问题。

### 3.3 E5/E6：读数以参照对为条件 + 读数群的用途

- **E5（跨实验室）**：DS 对同 200 条打分——corr(r\*_qwen, r\*_ds)=**0.13**；DS-r\* 的检测 AUC **0.42**（反号）；
  族均值相关 0.34。⇒ §6"跨实验室稳定"**证伪**。
- **E6（三对读数群）**：qw05 与 qw15 相关 **0.51**（同实验室跨规模），与 ds 0.45；检测 AUC：qw15 0.81 / qw05 0.73 / ds 0.42；
  3 维拼接 LOO 0.80（无增益）；**拼接 + s1 = 0.86（vs s1 单 0.73，+13pt）**；
  细粒度归因 NCM ≈ 随机（0.02–0.07）。
  ⇒ **读数群是真实的"第二检测信号"且与 s1 互补**；但归因靠它不行。

### 3.4 E8：几何诊断（悬案 3）

**数据**：B val 全量 7817（human 3000 / base 机 990 / instruct 机 3827），冻结特征 h（v1.0）。

| 检验 | 数字 | 含义 |
|---|---|---|
| d_HB（人−base 机）vs d_BI（instruct−base 机） | cos = **−0.91**（原始）/ +0.64（白化） | **人机轴与对齐轴不可分**（反向共线） |
| s1 ≈ 到 M_base 的距离？ | corr(dist, s1) = **−0.83** | 现象层面支持"法向坐标"叙事 |
| 三族位移谱（llama/qwen/yi） | 奇异值 1.55 / 0.72 / 0.25 | **低秩成立**；llama/yi 沿公共轴（0.84/0.86），qwen 垂直（−0.10） |
| 读出定位 | cos(w1, d_BI)=+0.85；cos(w2, d_BI)=−0.22；cos(w1,w2)=0.0002 | **s1 就在对齐公共轴上；s2 正交在外** |

### 3.5 E9：位移子空间的"新信号"检验（反转）

三族位移张成子空间（r=2/3）→ 样本投影：检测 LOO AUC **0.845**（≈s1 的 0.846）——初看是新信号；
**补齐检验：proj0 与 s1 corr −0.999**——公共轴就是 s1 轴本身（联合检测 0.845，增量≈0）；次轴检测 0.43–0.48、NCM 归因 0.07（全弱）。
⇒ **"位移子空间的检测分量 = s1"，没有免费的第二个检测维度**。

### 3.6 E10–E12：归因的形态——聚类死、判别活（悬案 2）

**数据**：394 对真同题配对（Qwen1.5B vs DS1.3B，CodeT5 v1.0 特征），Δ = h(x⁺)−h(x⁻)。

- **E10 聚类**：KMeans 纯度 0.52–0.60（GMM 0.60）——**不成簇**；跨族 Δ 方向 cos **0.998**（公共分量压倒——"两束几乎共线的锥"）；
  监督 LR 0.88；**Δs2（v1.0 单标量）的族判别 AUC 0.32**——s2 对族差异零敏感；
- **E11 判别（按题 GroupKFold，无泄漏）**：LDA **0.885** / LR 0.880 / 残差版 0.873/0.883（**残差化非必需**——判别器自动找正交切分）；
  残差 KMeans 0.546（仍不成簇）；公共轴 1D 0.39（公共分量对族分类无信息）；
- **E12 收内散间**：LDA 方向 1D 分割 in-sample 纯度 **0.9987**；**全维白化陷阱**——Σ_W/PCA 白化 + KMeans 0.50–0.55（马氏信噪比反降：
  Σ_B/Σ_W 型比 0.139 → 0.008——全维白化把"类内方差大的判别方向"也压小了）。
  ⇒ **"收内散间"的闭式最优 = Fisher 判别方向（限维数 r = 族数−1，不做全维白化）**。

### 3.7 E13：可学习的判别头（对闭式的挑战）

可微 Fisher 投影（log intra − log inter，3 seeds × r∈{1,2,8}）→ 按题 GroupKFold：**0.816/0.823/0.804 < 闭式 0.884**；
in-sample 收内散间成功（inter/intra=31×）。⇒ **小样本（788×768）下闭式统计解（+shrinkage）仍优**；端到端价值待大样本/多族释放。

### 3.8 E14：扩族验证——B 上"可以做但不行"

B val 分层 700 条 × **30 族**，3 参照对读数群的**判别式**归因：**7.7–8.0%**（随机 3.3%；NCM 8.1% 持平——信息量本身不足）；
单读数 5–6%、s1 单特征 6.1%。
⇒ 两条路的分工彻底清楚：**B 的归因（val .665）是"整模型 + 60K 样本"的高维学习**；**轻量归因必须"配对 Δ + 判别式"**——
B 无配对结构，做不了轻量归因。

### 3.9 E15：外部方案验证（K1 密度判别 / K2-lite 任务效应剥离）

（2026-09-27；接入外部研究方案（DCAN/DMHM 线）的首批验证；脚本 `scripts/kernel_e15_density.py`，产物 `runs/kernel_e15/k1_k2lite.json`）

**K1（逐类协方差/QDA，DMHM 思想）——部分成立，但机制与预期不符**：
- 原始 768 维逐类 QDA **全线失败**（acc 0.15–0.51，收缩越强越崩）——"判别信号集中少数方向"的又一独立证据（同 E12）；
- **LDA 5 维子空间内 QDA：acc 0.7826（+2.0pt，过预注册线）但 balanced 0.7125（−2.3pt）**——
  增益来自全局边界重塑（qwen05↔qwen15 互混 330→269，但向大类翻转：ds13 recall 0.68→0.52、qwen15 0.61→0.44）；
  **目标易混对 granite2b↔smollm2 完全未改善（272→270）**；
- 二分诊断：granite2b vs smollm2 的 QDA ≈ LDA（0.8477 vs 0.8472）——**二阶矩对该对零信息（此路线关闭）**；
  qwen05 vs qwen15 有 **+2.4pt**（0.7896→0.8132，同室代际对确有二阶信号）。
- ⇒ **不整体替换 DiscHead**；子空间 QDA 仅作为同室对的候选变体保留。

**K2-lite（逐题跨族中心化，DCAN 减法思想的闭式版）——显著成立**：
- 329 共同题（1974 样本）：**0.7239 → 0.7741（+5.0pt；bal 同步 +5.0）**；
- 逐族 recall 全线上升 +3~7pt；**granite2b↔smollm2 互混 −24%（79→60）**——目标对确被任务效应拖累；
- 性质：转导式（用同题其他族样本均值中心化，不用标签；按题 GroupKFold 无泄漏），与"归因需参照对"的部署约束一致。
- ⇒ **任务效应是泛化 gap 的重大成分**；"逐题中心化判别"升为归因头新默认口径候选（对齐口径 0.7741），
  K2-full（训练版残差分离）获得强依据。

### 3.10 E16：K2-full-lite（DCAN 训练版残差分离）——负结果 + 机理

（2026-09-27；脚本 `scripts/kernel_e16_dcan.py`；产物 `runs/kernel_e16/{dcan.json, dcan_aligned_ep100_*.json}`；
新增特征缓存 `runs/kernel_e16/h_*.npz`——双侧池化 h⁺/h⁻，与既有 Δ 逐位一致（max diff = 0.0））

- 结构：h_com = MLP(Δ)（512 hidden）→ h_spec = Δ − h_com → 族分类；损失 = CE + λ_rc·同题异族一致性（329 共同题）；
  5 折与闭式完全同折，闭式基线脚本内重算。
- **结果：全量 0.7529–0.7591（闭式 0.7626）；对齐 0.6809→0.6748（闭式中心化 0.7740）**；λ_rc 影响≈0；
  优化预算检查（100 epoch × lr{1e-3, 3e-4}）**不再改善**——非欠训练问题。
- **机理（关键）**：E15-K2-lite 的增益是**转导式**的——中心化用测试题其他族样本的均值；
  单-Δ 输入的训练版无法"摊销"它（**未见题的任务成分不可从单个 Δ 预测**）。训练版若要复现该能力必须
  **集合输入**（同题多族 Δ 一起喂）→ 指向相对表示/对比特征形态（待做）。
- 附：**中心化 + 子空间 QDA（LDA5-QDA）= 0.7791**（对齐新最佳，+0.5pt vs 0.7740；balanced 同步不降）。
- ⇒ "小样本下训练版 < 闭式"第 4 例（继 E13 后）；归因头默认仍取闭式（中心化 DiscHead，可选 +子空间 QDA）。
  （另：首轮 `cat` 臂因脚本未切换输入而与该行重复，作废。）

### 3.12 理论改写（一页）：双侧联合视角与 RLHF 两通道

（2026-09-27；判据实验 `scripts/kernel_e17e_symsplit.py` → `runs/kernel_e17/symsplit.json`）

**（1）视图谱系（实测）**：

| 视图 | 全量 | 对齐（中心化） |
|---|---|---|
| Δ（=反对称分量 A） | 0.7626 | 0.7741 |
| 对称分量 S=(h⁺+h⁻)/2 | 0.7715 | 0.7908 |
| **[h⁺;h⁻]（≡[S;A]，线性可逆）** | **0.8271** | **0.8571** |

单分量 ≈0.76–0.79，联合 +5~7pt——**归因信号在"对称 ⊕ 反对称"的联合结构里，任一半都不够**。
（注：[S;A] 与 [h⁺;h⁻] 信息等价；实测差 ≤2.2pt 为收缩正则的基相关效应。）

**（2）可加模型**：$h^{\pm}_{f,t}\approx \mu_t + a_f + b_f^{\pm} + \varepsilon$。
- $S=\mu_t+a_f$：中心化消 $\mu_t$ 得**族位置签名** $a_f$（双向共享）；
- $A=b_f/2$：**位移分量**（≈旧 Δ 视图）；
- 联合判别 = 同时利用"这族长什么样"（$a_f$）与"对齐把它推了多远、往哪推"（$b_f$）。

**（3）RLHF 两通道**：$\log p_{i_f}=\log p_{b_f}+r_f/\beta-\log Z_f$——族身份经两条独立通道进入样本特征：
① **$p_{b_f}$ 的流形位置**（预训练数据/风格分布）→ 进入 $a_f$；
② **$r_f$ 的偏好几何**（对齐配方）→ 进入 $b_f$。
实测两通道都真实（单独各 ≈0.76–0.79），**联合最优**；"位移近共线"（cos 0.998）只说明 $b_f$ 的均值方向跨实验室收敛（对齐趋同），不否定样本级增量。
旧 s2（Δ-only）是**丢掉通道①的欠定版本**。

**（4）裁决与定义**：s2-v3 = **[h⁺;h⁻]（±逐题中心化）上的判别式**；Δ 降级为分量视图（低成本/无对照场景的兜底）。
检测侧不变：公共轴（≡s1）量级管检测，联合判别子空间管归因。

**（5）可检验预测**：
- P1 ✅（E17e）：单分量 < 联合（.7715/.7626 < .8271，全量）；
- P2（设计）：中心化增益 ∝ 题目项能量 $\|\mu_t\|$（per-task 回归可验）；
- P3（待新族）：引入"非常规对齐配方"的族 → 其 $b_f$ 方向应偏离公共轴、A-alone 分辨力上升；
- P4（待 K3，token 级）：逐 token 归因应富集于风格 token（命名/格式）。

### 3.13 E18：v0.8 三线验证（中心化算子化 / 度量分块化 / 坍缩度先决）

（2026-09-27；`scripts/kernel_e18_v08.py` → `runs/kernel_e18/v08.json`；沿线预注册判读）

**（1）A 线——中心化算子化（转导中心化能否换成"免测试统计"的归纳算子）**
- 谱结构：1304 题的任务中心（每题各族样本均值）SVD——plus 侧 rank90=8、rank95=30；
  minus 侧 rank90=17、rank95=53（前 100 方向含 0.97–0.98 方差）。**任务中心变化极端低秩**——谱条件（rank90<50）满足。
- 归纳投影（训练折拟合前 r 主方向 U → 样本投正交补 I−UUᵀ），aligned 基线（不投影）0.7827：

  | r | 10 | 30 | 50 | 100 |
  |---|---|---|---|---|
  | acc | 0.7720 | 0.7685 | 0.7690 | 0.7457 |

  full 口径：r=10 → 0.8241（基线 0.8271），r=100 → 0.7375——**单调恶化**。
- **判读：未达预注册线（≥0.8471）→ 中心化不可算子化**（且全面劣于不投影基线）。两段论证：
  ① 共享低秩子空间**与族判别方向共线**——投影它连带伤信号（r↑ 单调降即证）；
  ② 投影共享部分零增益，而中心化在 aligned 上净增 +7.4pt——**收益只能来自逐任务特异残差 μ_t 的非共享部分**，该部分无法用别的任务估计。
  → 修正直觉："任务中心低秩"≠"免参照算子可行"；**"同题参照"接口保留为部署约束**。

**（2）B 线——度量分块化（S/A 通道独立组合能否替代联合视图）**
- 全量：S 0.7715 / A 0.7626 / 分块 argmin(d_S+d_A) 0.7896；错误相关 kappa=0.546；独立上限 1−e_S·e_A=0.9458。
- 对齐中心化：S 0.7908 / A 0.7741 / 分块 0.8095；kappa=0.484；独立上限 0.9527。
- **判读：未达预注册线（分块 ≥0.8371 且 kappa<0.3）→ 通道独立假设被否**。分块仅回收约一半的联合增益
  （+1.8/+1.9pt，联合为 +5.5~6.6pt），S/A 错误高度相关——**互补机制 = 交互式（联合判别子空间的交叉结构），非独立误差抵消**；
  [h⁺;h⁻] 联合视图不可拆成廉价双头。

**（3）C 线——坍缩度先决检查**：现存配对 parquet 每 (题,族) 仅 1 对（无同题多采样存量）→
**parked**（需先做多采样生成，按路线文档排队，不阻塞 A/B）。

**（4）净读**：两条主攻线均为负，但给出三个结构性事实：
① μ_t 低秩（8/17）≠ 可归纳——低秩的是"共享"部分，真正要扣的特异残差不在任何跨任务共享子空间里；
② 把中心化收益夹逼定位到"逐任务特异残差"；③ 互补=交互而非独立。
部署侧维持原状：**转导接口保留、联合视图保留**。

## 4. 最终结论：双信号体系的形态（对设计文档的净修订）

**保留**：$\ell=\ell_1+\ell_2$ 的可加分解（数学推导不变）；s1 的检测主人地位（并新增"$r^*$ 读数群"作为互补信号）。

**修订**（全部有实验支撑）：
1. $s_2$ 的**单标量形态废弃**（聚类/单方向读出/对级训练均被证伪）；
2. $s_2$-v2 **定义为"配对 Δ 的判别式读出"**：线性判别投影（r = 族数−1，LDA/shrinkage 闭式）+ 族原型；
   检测归 s1、归因归判别头——**分工制**；
3. **免标注原理限定为"指定参照对"**：$r^*$ 以模型对为条件（跨实验室 0.13），无可移植的全局方向；
4. **几何修订**：对齐位移的公共轴 ≡ s1 轴（corr −0.999）——"检测与对齐"在**冻结特征空间不可分**；
   分离只发生在"**配对差 Δ 的判别子空间**"里——这正是"检测/归因分工"的几何基础；
5. **部署约束**：归因能力**必须**有参照对（同题 x⁺/x⁻ 或可生成变体）——这是新的接口要求。
6. **归因主视角修订（E17 系列，2026-09-27）**：归因 = **双侧联合视图 [h⁺;h⁻]（±逐题中心化）的判别式**；
   对称/反对称分量单独都弱（.77/.76）、联合才强（.8271/.8571）——对第 4 条后半句的修订：
   分离发生在**双侧联合判别子空间**。见 §3.11–§3.12。

   ★ E18-A 已证**不可算子化**（归纳投影 r=10–100 全面劣于转导中心化，见 §3.13）——转导接口保留为部署约束，无免参照替代。

**（C）理论缺口**
6. **S/A 互补的机理**：联合>任一分量（E17e）已确认；E18-B 已量化（§3.13）：错误相关 kappa≈0.48–0.55、
   分块独立组合只回收约一半联合增益 → 互补为**交互式**（联合判别子空间的交叉结构），非"独立误差抵消"；
   彻底信息分解（哪些维度/为何交互）待做（对应预测 H4）；
7. **统一叙事未打通**：检测（s1/r\*）与归因（联合视图）尚缺“同一座桥”——
   r\* 公式只保证“两版分差”的可测量，位置项对应的可测标量未定（P2/P3 未验）；
8. **内容 vs 风格未分解**：h 含内容信息；中心化只扣“题-组均值”——对归因任务合法，
   但解释性叙事需谨慎（“风格”与“写出的内容不同”未严格分离）。

**（D）覆盖与部署**
9. 覆盖仅：6 族、代码域、英文题集、0.5–2B 小模型；跨语言/跨域/大模型未测；
10. **闭源模型（无 base/instruct 配对）不可用**——轻量归因在无配对时失败（E14、SemEval-B 实证）；风格伪装/对抗未测；
11. 新族加入成本 ≈ 每族两版模型 × 1300 题生成（约 65 分钟 GPU）。

**（E）文档/工程**
12. 数字口径曾多次漂移（0.7626→…→0.8571），现以“补注机制”管理；kernel/handoff/d-det.md/standalone 四处存在结论复述，维护需谨慎；

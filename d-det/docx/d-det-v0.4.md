## 1. 设计与决定（用户五选）

| 项 | 决定 | 落地 |
|---|---|---|
| 实验组织 | **一个实验内两轴同做** | v0.4.0 = s1 斥力 + s1 引力 + s2 跨族引力 |
| 斥力形态 | **仅固定 margin**（softplus，饱和） | `loss.rep`：`softplus(m − (2y−1)·s1)`，m 由 P5 分位标定（4ep dump → **4.528**） |
| 引力形态 | **Fisher 判别比** | `FisherEMA`：R=(μA−μH)²/(σA²+σH²)，损失 softplus(log4 − logR)，EMA 在线（batch=1 友好） |
| 维度问题 | **加"去冗余"对照臂** | v0.4.1 = v0.4.0 + `CovEMA`（相关矩阵非对角平方，Barlow/VICReg-lite） |
| 基座 | **v0.3.0 4ep 的 last.pt** | 各臂 2ep（跨方法 resume） |

文献映射：斥力 = margin 家族（L-Softmax/CosFace/ArcFace，DMHM energy margin 同型）；饱和特性=到 margin 外梯度→0（"越靠近 0 力越大"）；
Fisher = 类内聚拢+类间拉开的比值形态（center loss/SupCon 的统计版）；跨族方向引力 = 把不同族的 base→instruct 位移方向聚拢（DMHM Laplacian 平滑的精神）；
去冗余 = Barlow Twins/VICReg（**非**"信息压制"；对抗式移除已被证不可靠，Elazar&Goldberg 2018）。

## 2. 实施与配方

**代码改动（全部落盘并过编译/冒烟）**
- `models/scores.py`：`forward_feat()`（几何损失复用同一次前向）；
- `train.py`：`s1_margin_loss` / `FisherEMA` / `CovEMA` + `pairxf` 分支 + `evaluate(pairxf)`（dir_cos/dir_acc 诊断）+ 日志列 `loss_rep/fisher/xfam/cov`；
- `dataio`：`PairXFDataset`（pairs.parquet × pairs_qwen15 **按 task_id 对齐**；qwen15=已见族、ds13 held-out）+ `collate_pairxf`；
- `configs/ddet_v040.yaml`（rep 1.0 / fisher 1.0 / xfam 0.5）、`configs/ddet_v041.yaml`（+cov 10.0）；
- `scripts/`：`calibrate_margin.py`（P5 标定；2ep dump 2.687 → 4ep dump **4.528**）、`check_v040_grads.py`（**四项首步梯度非零 PASS**）、
  `queue_v040.sh`（自动衔接：等 4ep → 标定 → 冒烟 → v0.4.0 → 探针 → v0.4.1 → 探针 → 汇总）。

**配方**：四流 [m4, hybrid, pair, pairxf] 各取 1 样本/步；grad_accum 8；lr 头 3e-4 / enc 2e-5；bf16；每 epoch **≈3.55h**（四流比三流 +60%）；
每臂 2ep ≈ 7.1h + 评测/探针 ≈5min。Fisher：momentum 0.95、target ln4、warmup 24、min_gap 0.05。

**损失轨迹（2ep 内）**

| 项 | v0.4.0 起→末 | v0.4.1 起→末 | 读 |
|---|---|---|---|
| rep | 0.280 → 0.095 | 0.279 → 0.087 | 边界带被压（margin 4.528） |
| fisher | 0.153 → 0.073 | 0.154 → 0.068 | 类间/类内比向目标爬 |
| xfam | 0.175 → **0.0036** | 0.178 → 0.0040 | 跨族 Δ 方向 cos 0.825→0.996（pairxf 评测 cos 0.998） |
| cov | — | 0.513 → 0.165 | 去冗余项正常下降 |

**工程记录（踩坑与修复）**
1. **best.pt 缺失坑（2026-09-24 实测）**：resume 续训时 monitor 未超过 resume 分数（v0.4.1：0.9232 ≤ 0.9233）
   → `best.pt` 从未写出 → 队列评测/探针全部 `FileNotFoundError`。
   修复：**训练侧保底**（未超分时 `best.pt = last.pt`，train.py）+ **队列侧回退**（`CKPT=best.pt; [ -f ] || CKPT=last.pt`）；
   v0.4.1 随后用 `last.pt`（epoch5）补评测，读数与本部一致。**教训：以 best.pt 为契约的下游必须设保底**。
2. CPU 集成冒烟在训练并发时被内存击杀（默认 8 个 dataloader worker）→ 冒烟必须 `--set train.num_workers=0`。
3. tqdm 的 `\r` 会把训练日志撑大（r2 日志 ~百 MB 级）——排查用 metrics.csv，不要在日志上 grep 全量。

## 3. 结果

### 3.1 m4（F1 优先，见 §0 表）

- v0.4.1 追平 u-det v0.4.4（**F1 0.9775 = 0.9775**）与 v0.3.0 2ep 峰值（0.9776），差异在噪声内（n=1940，σ≈0.34pt）；
- v0.4.0 的 F1 0.9766 介于 4ep（0.9756）与 2ep 峰值之间；两臂的 AUC（0.9955/0.9953）比 2ep（0.9966）/4ep（0.9969）略降
  ——斥力/Fisher 让边界更"锐"，但排序质量（AUC）未同步提升。

### 3.2 hybrid（见 §0 表）

- 两臂都在 v0.3.0 的爬升轨迹上继续（4ep→v0.4.0：+0.36/+1.66/+0.34pt）；
- **line F1 已微超 u-det v0.4.4**（0.7881/0.7877 vs 0.7878）；chunk 破 0.5；token 距 u-det 仅 0.2pt，距 base_codet5_tok（0.8270）约 1pt。

### 3.3 片段（见 §0 表）

- **v0.4.0 是三版里中段修复最好的**：mid 0.9026（4ep 0.8840 → **+1.9pt**；距 abA 0.9165 差 1.4pt）；
  head/tail 也创版本最佳（0.9560/0.9329）——正对准"边界带施力"的设计目标；
- **v0.4.1（+白化）**：full/full_frag 最好（0.9820/0.9861），但 **mid/head/tail 小幅回退**（0.8886/0.9537/0.9282）
  ——去冗余与"中段尖锐化"存在轻微对冲。

### 3.4 跨规模/跨族（qwen1.5 与 DeepSeek；fused=LR 5×4 CV）

| 口径 | abA | 4ep | v0.4.0 | v0.4.1 |
|---|---|---|---|---|
| qwen15 ref s1 / fused | 0.9793 / 0.9794 | 0.9931 / 0.9929 | 0.9899 / 0.9885 | 0.9901 / 0.9889 |
| qwen15 instruct s1 / fused | 0.9821 / 0.9821 | 0.9911 / 1.0000 | **0.8597** / 0.9962 | **0.8777** / 0.9987 |
| qwen15 base s1 / fused | 0.9519 / 0.9523 | 0.9887 / 0.9881 | 0.9873 / 0.9881 | 0.9866 / 0.9878 |
| ds13 instruct s1 / fused | 0.9787 / 0.9787 | 0.9892 / 0.9999 | **0.8504** / 0.9981 | **0.8694** / 0.9992 |
| ds13 base s1 / fused | 0.9609 / 0.9605 | 0.9840 / 0.9846 | 0.9817 / 0.9818 | 0.9809 / 0.9812 |
| instruct 的 **s2\***（best-signed） | — | 0.8342 / 0.9817 | **0.9998 / 1.0000** | **0.9999 / 1.0000** |

**最重要的 trade-off（两臂一致）**：
1. **s2 轴被大幅增强**：s2\* 从 0.83 级升到 **≈1.0**（跨族未见族的 instruct 检出），s2 分数尺度 ~×2.3（pair Δmean 2.71→6.48/5.37）；
2. **s1 在 instruct 风格 OOD 上崩了**（0.99→0.85~0.88）：分布内更锐利（片段/头尾↑），但家族外的生成风格上判别退化；
3. fused 稳定在 0.996~0.999——**融合层吸收了 s1 的漂移**，但"单头可迁移性"的叙事需要用 s2 补位说。

### 3.5 两臂对照小结

| 指标 | 更好的一臂 | 备注 |
|---|---|---|
| m4/test F1 | **v0.4.1**（0.9775） | +0.09pt；白化对分布内略有益 |
| 片段 mid / head / tail | **v0.4.0**（0.9026 / 0.9560 / 0.9329） | 去冗余对冲了中段收益 |
| 片段 full / full_frag | **v0.4.1**（0.9820 / 0.9861） | |
| hybrid | 持平（±0.03pt） | 两臂几乎相同 |
| s1-OOD（instruct） | v0.4.1 略好仍崩（0.878/0.869） | **白化不是解药** |
| 结论 | 去冗余（covreg）的作用 = 分布内微增益 + 中段回退，**不支持"显式抑制其它维度"的必要性** | 与文献预期一致（§1 文献映射） |

## 4. 判定与下一步

1. **"显著超越全量微调 CodeT5"**：m4 主口径仍是打平带（F1 0.9756~0.9776 全在 ±1σ 内）；
   唯一有希望"显著"的口径是**跨族/OOD + 零标注第二轴**（s2\*≈1.0、fused 0.996~0.999）——
   但**真基线（base_codet5_ft/tok）在同一跨族池子上的读数从未测过**，这是判定"显著"的最后拼图（补测成本 ~1h，只推理）。
2. **s1-OOD 回落的归因**（待做）：三个嫌疑（固定 margin 过锐、Fisher 类内收紧、xfam 通过共享编码器施压）；
   若需定位：单变量臂（如仅 rep、margin 减半）——按预算纪律，各 2ep，但先做免费的分析（分数分布/错误剖析）再决定。
3. **片段 mid**：v0.4.0 已到 0.9026，仍是唯一落后 abA（0.9165）的项；mid 增强（行窗增强）列后续。
4. **公平性补测**：hybrid 与基线口径差（我方非重叠分块 vs 基线 stride-256 滑窗）——补 stride-256 评测可再赢 ~1pt 的公平性解释空间。
5. **外部基准探针**（§5）：SemEval A/C 零训练探针 + stride-256 评测 + 真基线跨族补测，三项按序做（均只推理）。

## 附（2026-09-24 补跑）：P1 探针——s2 的家族可分性（回应"为什么 s2 区分家族能力不强"）

脚本 `scripts/probe_s2_family.py`（qwen15/ds13 同题 394 对；v0.3.0 无 xfam vs v0.4.1/v1.0）：

| 指标 | v0.3.0 | v0.4.1 (v1.0) |
|---|---|---|
| s2 族内 plus>minus AUC | 1.000 / 0.9998 | 1.000 / 1.000 |
| s2 族间 AUC（plus / minus） | 0.277 / 0.253 | 0.295 / 0.511 |
| s1 族间 AUC（plus） | 0.634 | 0.527 |
| Δh 方向 cos（跨族 / 族内×2） | 0.769 / 0.775, 0.746 | 0.996 / 0.997, 0.994 |
| **Δ 残差族别 AUC**（GroupKFold 按题分组） | **0.978** | **0.986** |
| 残差纯方向 AUC（单位化） | 0.979 | 0.988 |
| 全 Δ 纯方向 AUC | 0.982 | 0.984 |
| 残差/Δ 范数比 | 0.445 | 0.057 |

**结论**：
1. s2（rank-1 标量）只承载"族间公共的奖励位移轴"——族内排序满分、族间零可分（s2 族间 AUC<0.5 仅为
   系统性族偏置）。跨族 dirac≈1、融合可拉起任意 s1，与"不能分族"是同一枚硬币的两面；
2. **家族方向指纹存在于 Δ 残差**（0.98 可分，纯方向亦然）——v0.4 的 xfam 把残差压到 5.7% 幅度但信息未丢；
3. 归因能力的修复 = 设计原案：低秩 r=4~8 的带符号方向读出 + 跨族对比信号；检测（公共轴）与归因
   （残差子空间）可分工，检测端现状不受影响。

**2026-09-25 跟进**：SemEval-B 上的秩扫描已补跑（`docx/d-det-semeval.md` §6）：冻结特征下 CE 瓶颈
r=8~11 平台且优于全维直连（约束即正则）；纯铰链子空间（四族 8 模型）只承载弱家族信息 → 归因须家族监督/残差对比。
**r\*=8** 将用于 A/C 特征管线。

## 1. 数据与协议落实（规范 §4）

1. **子集**：E26 固化强模型规则（五模型五个 generator、四家族 OpenAI/DeepSeek/Mistral/Google，
   Mistral 含两个 generator）。计数与预计 4013/1654 完全一致；"已见来源的未见代码归因"，
   不写成多家族新旗舰迁移。语言/长度桶随附（§2）。
2. **表示**：仅复用 E28 `raw`（原 split/row，不合并）；标准化统计仅 AI 子集训练折（std 下限 1e-2）。
   编码器冻结；MLP **每臂重新初始化**，未加载 E24/E27 监督头。
3. **B0**：逻辑回归 C=.1、tol=1e-6、max_iter=1e4、收敛（n_iter 348）；权重
   `N/(K·|G_f|·N_g)` 使加权目标与 B1/B2 的平衡采样一致。
4. **B1/B2**：u=ã+V·GELU(U·ã+b1)+b2，h=u/max(‖u‖,1e-6)；U Xavier、V std=1e-3、bias 0；
   W_F(4×768) Xavier。批 128=4 族×32（族→generator→样本均匀；每族≥2 distinct，重抽 0 次）；
   steps=32/epoch×2 epoch **同推进、同 seed=0、同批序**；AdamW lr 1e-3、wd 1e-4、clip 1；
   **取 epoch 2**。L_B1=L_F；L_B2=L_F+0.1·L_C（SupCon：A(i)=B\{i}、P=同族、τ=.1 只除一次、
   两项回传同一 u/h）。
5. **检测**：ã 上二项逻辑回归（AI 子集+Human 8000 训练；C=.1）拟合后冻结；B1/B2 不改；
   该检测一致来自实验结构，**不作为 H3 的证据**。
6. **去重**：子集 ids 精确审计 train 内 0 组、train↔val 0；剔除清单为空（不删除样本）；
   近重复沿用 E26 记录（子集相关：Mistral-7B 同 generator 1 对）；无 task_id，不声称题目不交。

## 4. E30 出口解释勘误（同步写入 E30 报告 §7 与 README）

1. **撤销**"留出分数必须超过随机切分才能启动方法实验"的出口规则——它混淆了"**能否迁移**"与
   "**迁移是否无损**"；随机切分是迁移损失参照，不是机会水平。历史 `passed=false` 保留，
   不重新宣称旧预注册出口通过；仅新增解释规则版本。
2. 正确判读：**存在高于机会水平（1/7≈.1429）的描述性跨 generator 可分性，且存在明显迁移损失
   与 generator 异质性；稳定性与混杂仍待检验。**
3. 合并互补两折全部留出预测重算（各家族/generator 权重不同 ⇒ 合并值≠两折简单平均）：
   raw **BA_F=.24026 / BA_G=.25168**（服务器端已从 `predictions.npz` 独立复核，与指导端数值一致）；
   μ BA_F=.23983 / BA_G=.25394（指导端计算值）。
4. 对角高斯失败**不能**证明"信息必在跨维协方差中"。
5. 所有读出依赖经监督微调的 v1.0 编码器：**"raw"不是"未经目标监督的表示"**。训练数据重叠
   核实（补充至 manifest）：配置级——v0.4.1 训练数据仅 m4/hybrid/pairs/pairs_qwen15（无 SemEval）；
   内容级——Task B train/val 抽样 4000 条解码 vs 内部 31978 条码：精确归一化 0 命中、标识符集合
   0 命中；且使用的是 v0.4.1 权重（SemEval 适配微调检查点未被使用）。边界声明：判别性仍来自
   u-det 内部监督，不改变"监督表示泄漏需持续声明"的事实。

## 5. 结论与边界（规范 §5）

1. **本轮结果（预声明三出口的第 3 条）**：B2 相对 B1 无实用增量（+0.11pt < 1pt），且两神经臂
   均未超过线性基线 B0 ⇒ **记录负结果**；不增加多个损失解释失败；按指导，下一步**只选择一个
   具体表示瓶颈检验**（例如 2-epoch×32-step 的优化预算 vs 几何容量，二者择一，受控设计）。
2. **不得外推**：不否定 H2 本体（只否定该实例化）；不把 B1/B2<B0 读成"非线性无用"；不把
   检测一致读成 H3 分离。样本相关性（同 generator 正对占绝对多数）、两 epoch 欠拟合、无 task_id
   三项限制分别报告。
3. **论文口径**：后训练分布重加权理论动机 → H1 可观测来源证据（E30 勘误后版本）→ H2 同容量
   几何消融（本轮该实例化不支持）→ H3 任务干扰（未检验）；每轮只添加/修订一个可操作假设。

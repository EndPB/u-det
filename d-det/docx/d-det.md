## 0. 总纲：一次推导，两个坐标

全部从 RLHF 的闭式解出发。对齐目标为

$$\max_\pi\; \mathbb{E}_{x\sim\pi}\big[r(x)\big] - \beta\,\mathrm{KL}\big(\pi \,\|\, p_{\text{base}}\big)$$

其最优解有精确形式：

$$p_{\text{RLHF}}(x) = \frac{1}{Z(\beta)}\, p_{\text{base}}(x)\, e^{r(x)/\beta},\qquad Z(\beta)=\int p_{\text{base}}(x)\,e^{r(x)/\beta}\,dx$$

对人类分布取对数几率比，代入上式：

$$\ell(x) \;:=\; \log\frac{p_{\text{RLHF}}(x)}{p_H(x)} \;=\; \underbrace{\log\frac{p_{\text{base}}(x)}{p_H(x)}}_{\displaystyle \ell_1(x)\;\longleftrightarrow\;s_1} \;+\; \underbrace{\frac{r(x)}{\beta} - \log Z(\beta)}_{\displaystyle \ell_2(x)\;\longleftrightarrow\;s_2}$$

**检测信号被数学强制分解为两个可加因子**。$s_1, s_2$ 分别是 $\ell_1, \ell_2$ 的学习近似。下面逐维展开。

## 1. 统一符号表

| 符号 | 类型 | 含义 |
|---|---|---|
| $x \in \mathcal{X}$ | 程序 | 待检代码片段，默认函数级 |

| $d_1,\dots,d_n$ | 决策点 | $x$ 的形式选择序列（命名、分支风格、错误处理、docstring……） |
| $z = f_\theta(x) \in \mathbb{R}^d$ | 向量 | 编码器原始特征 |
| $s_1, s_2 \in \mathbb{R}$ | 标量 | 两个判别分数（新维度激活值） |
| $u_1, u_2$ | 向量 | 读出方向（若用探针式读出） |
| $p_{\text{base}}, p_{\text{RLHF}}$ | 分布 | 同族基础模型 / 对齐版 |

| $\beta>0$ | 标量 | KL 约束强度（不观测） |
| $\hat{r}=\nabla r/\|\nabla r\|$ | 向量 | 奖励梯度方向 |
| $\mathcal{M}_{\text{base}}, \mathcal{M}_{\text{RLHF}}$ | 流形 | 基础众数流形 / 倾斜后流形 |
| $y\in\{0,1\}$ | 标签 | 人类 / AI |

## 2. 第一维 $s_1$：众数坍缩度

**理论定义**（等价类内条件化，消任务因子）：

$$s_1(x) \;\approx\; \log\frac{p_{\text{base}}\big(x \mid \mathrm{Eq}(x)\big)}{p_H\big(x \mid \mathrm{Eq}(x)\big)}$$

**决策点近似展开**（设各决策点条件独立）：

$$s_1(x) \;\approx\; \sum_{i=1}^{n}\;\log\frac{p_{\text{base}}(d_i \mid \mathrm{Eq})}{p_H(d_i \mid \mathrm{Eq})}$$

每一项的含义：决策点 $d_i$ 上，人类分布是**尖峰**（个人先验：习惯用 `idx`、习惯提前返回），base 模型分布是**平顶且压向条件众数**（训练目标使然：平滑 + 取局部最优）。单测量的是"这个选择偏离人类尖峰、趋向群体平均的程度"，聚合 $n$ 个决策点即总坍缩度。

**几何**：$s_1$ = 到基础众数流形的**法向坐标**。

$$s_1 \;\sim\; d_\perp\big(z,\; \mathcal{M}_{\text{base}}\big) = \big\| z - \mathrm{Proj}_{\mathcal{M}_{\text{base}}}(z) \big\|$$

- 人类代码：粗糙散布在流形外侧 → $d_\perp$ 大
- base 模型代码：贴流形 → $d_\perp \approx 0$
- RLHF 代码：贴（被收紧后的）流形 → $d_\perp \approx 0$ —— **$s_1$ 对两者同判为 AI**，这正是它作为"是不是 AI"主判据的原因

**关键不变性**：$s_1$ 由**采样器性质**决定（分布方差坍缩），不随推理时指令变化。"写得随意点"的指令让模型从"窄的随意风格模式"里采样——分布依然是窄的。这是 $s_1$ 抗伪装指令的理论根据。

**弱点**：众数位置逐代漂移（每代 base 模型换众数），$s_1$ 是代际敏感的指纹，需定期用新 base/instruct 配对重校准。

## 3. 第二维 $s_2$：偏好位移度

**理论定义**（直接来自倾斜公式）：

$$s_2(x) \;\approx\; \frac{r(x)}{\beta} - \log Z(\beta) \;\approx\; \log\frac{p_{\text{RLHF}}(x)}{p_{\text{base}}(x)}$$

**免标注估计原理**（这是 $s_2$ 最漂亮的部分）：同一家族的 instruct 版与 base 版，比值恰为

$$\frac{p_{\text{instruct}}(x)}{p_{\text{base}}(x)} = \frac{e^{r(x)/\beta}}{Z(\beta)} \;\;\Longrightarrow\;\; \log\frac{p_{\text{instruct}}(x)}{p_{\text{base}}(x)} \approx s_2(x)$$

于是训练信号**不需要任何人类标注**：取同任务配对 $(x^+ = \text{instruct 输出},\; x^- = \text{base 输出})$，施边际损失

$$\mathcal{L}_2 = \sum_{(x^+,x^-)} \max\!\big(0,\; m - s_2(x^+) + s_2(x^-)\big)$$

学到的 $s_2$ 就是奖励方向 $\hat{r}$ 上位移量的单调代理。

**几何**：$s_2$ = 沿 $\hat{r}$ 的**切向位移坐标**。一阶近似下两流形关系为

$$\mathcal{M}_{\text{RLHF}} \;\approx\; \mathcal{M}_{\text{base}} + \tfrac{1}{\beta}\,\bar{\Delta}_r,\qquad \bar{\Delta}_r \propto \hat{r}$$

即倾斜把流形整体沿奖励方向平移并收紧（对齐压缩输出多样性 → 流形从曲面收成针状）。$s_2$ 读的是"被推了多远"。

**代码域的具体子方向**（$r$ 在代码上的可观测分量）：docstring 完整度、防御性错误处理、过度类型标注、对称分支结构、规范化命名。全部是**形式语义**分量——计算语义的均值 RLHF 不动，故"与计算语义正交"这个构成性约束在倾斜前后都成立。

**必须诚实的一处**：$s_2$ 单独判别力弱。人类在偏好维度上分布**宽**（勤奋的人也写完整 docstring，$r$ 值高），AI 被倾斜后集中在高 $r$ 区——人类分布尾部覆盖 AI 众数。所以 $s_2$ 的判别力来自"人类方差大 vs AI 集中"的分布形状差，必须与 $s_1$ 联合使用。$s_2$ 的真正强项是**稳定性与归因**，不是单独检测。

> **⚠️ 2026-09-25 实证修正（免标注原理的检验；kernel E1/E2/E5/E6，产物 `runs/kernel_e*/`）**：
> 用 Qwen2.5-Coder-1.5B/0.5B、DeepSeek-Coder-1.3B 三组 base/instruct 对同族样本直接打分
> （$r^*=\log p_i(x)-\log p_b(x)$，B val 分层 200 条）：
> ① **单家族内坚实成立**——Qwen-1.5B 的 $r^*$ 人机检测 AUC **0.81**（免训练）、三分组单调
> （人 −22.5 → base 机 −13.6 → instruct 机 −4.8，ANOVA **p=8e-9**）、族间结构显著（Kruskal p=0.003）；
> ② **学习代理与它对不齐**——四种配置（hinge/BT × 0.5B/1.5B 配对监督）的线性读出与 $r^*$ 相关性
> 一律 ≈ **−0.23**（反号且与配置无关）：不是损失形式问题，是单一全局方向假设的系统性缺陷；
> ③ **跨模型对非通用**——Qwen-1.5B 与 DeepSeek 的 $r^*$ 互相关仅 **0.13**（同实验室 0.5B↔1.5B 为 0.51），
> 读数以参照模型对为条件。
> ⇒ §3 的"免标注估计"在**指定模型对**下有效；"与参照无关的单一位移标量"不成立（详见 §6/注记 1 修订）。

## 4. 联合结构：$(s_1, s_2)$ 平面

| 象限 | $s_1$ | $s_2$ | 语义 |
|---|---|---|---|
| ① | 高 | 高 | 典型 instruct/RLHF 代码（贴流形 + 被偏好推远） |
| ② | 高 | ≈0 | base 模型代码（贴流形，无对齐指纹） |
| ③ | 高 | 负/回移 | 伪装指令下的对齐模型（"写像人" = 反向倾斜 $e^{-r/\beta}$） |
| ④ | 低 | 任意 | 人类代码（远离流形，$s_2$ 位置取决于个人风格） |

**联合检测分数**（文件级，GMM 聚合）：对函数级分数 $\{(s_1^{(k)}, s_2^{(k)})\}_{k=1}^N$ 拟合二维两成分混合

$$p(\mathbf{s}) = \pi_H\,\mathcal{N}(\mu_H, \Sigma_H) + \pi_A\,\mathcal{N}(\mu_A, \Sigma_A)$$

$\hat\pi_A$ 即 AI 函数比例（协写检测）。**仓库条件化**：$\mu_H,\Sigma_H$ 用同仓库人类代码初始化——$p_H$ 从总体分布换成 $\text{repo}$ 条件分布，消掉团队风格混淆。

**正交性的来源是结构性的，不靠人工强制**：$\mathcal{L}_1$（人 vs AI）的监督梯度只跨人机边界，$\mathcal{L}_2$（base vs instruct）的监督梯度只在 AI 内部有差异——两个损失的监督信号统计上互不重叠，自然诱导两头分离。加保险正则 $(u_1^\top u_2)^2$ 即可。

> **⚠️ 2026-09-23 实证修正（§4 正交论断）**：消融 B（λc=0，见 `docx/d-det-v0.1.md` §5.6-B）
> 实测 |cos(w1,w2)|≈0.74——「正交性来源是结构性的、不靠人工强制」**不成立**：
> 两读出会自然共线，λc 是实现两维解耦的**必要条件**（而非「保险」）。

## 5. 架构与总损失

**扩张**：$\mathbb{R}^d \to \mathbb{R}^{d+2}$（或 $d+r,\ r\geq 2$），新通道权重零初始化：

$$s_1 = \alpha_1\, w_1^\top g_1(z),\qquad s_2 = \alpha_2\, w_2^\top g_2(z),\qquad \alpha_1=\alpha_2=0 \;\text{（初始）}$$

**总损失**：

$$\mathcal{L} = \underbrace{\lambda_a\sum \mathrm{BCE}\big(\sigma(s_1),\, y\big)}_{\text{人机分离}\,\to\,s_1} + \underbrace{\lambda_b \sum \max(0, m - s_2(x^+) + s_2(x^-))}_{\text{base/instruct 差分}\,\to\,s_2} + \underbrace{\lambda_c (u_1^\top u_2)^2}_{\text{正交保险}} + \underbrace{\lambda_d \big\|z_{\text{旧}} - f_{\theta_0}(x)\big\|^2}_{\text{旧维语义保持}}$$

**硬约束不入损失**：计算语义正交性由数据构造保证——配对双方必须都通过同一测试（SWE-bench 式），等价类条件在数据层面强制成立。
（v0.1 的实际执行：**同 prompt 近似**，测试回测留到后续严格档，见附录 B.5。）

## 6. 性质对比速查卡

| 性质 | $s_1$（众数坍缩） | $s_2$（偏好位移） |
|---|---|---|
| 锚定对象 | base 模型采样分布 | 人类偏好结构（跨实验室稳定） |
| 理论对应 | $\log\frac{p_{\text{base}}(x\mid\mathrm{Eq})}{p_H(x\mid\mathrm{Eq})}$ | $r(x)/\beta - \log Z$ |
| 几何角色 | 法向坐标（离流形距离） | 切向坐标（沿 $\hat r$ 位移） |
| 代际漂移 | **大**（众数位置换代） | **小**（方向锚定偏好，但纪元级符号翻转） |
| 指令敏感性 | **低**（采样性质，伪装指令打不动） | **高**（反向倾斜可回移） |
| 标注需求 | 人/AI 配对 | **零标注**（base/instruct 差分） |
| 单独检测力 | 强 | 弱（人类覆盖偏好维度） |
| 附加能力 | — | 归因（方向+幅度 → 模型家族） |

> 互相关仅 0.13~0.51（实验室内部 0.5B↔1.5B 为 0.51 > 跨实验室 0.13）；"代际漂移小"应限定为
> "同一实验室/配方内"。修正后表述：**$s_2$ 锚定的是参照模型对的位移方向，方向是"谱系/配方"的属性**。
> 新证据（E6）：**多参照 $r^*$ 读数与 $s_1$ 融合把检测 AUC 从 0.73 推到 0.86**——位移读数群与 $s_1$
> 强互补（与 A 任务 rvoid+s1 融合 0.7492 同型）。

## 7. 两条实现注记

**注记 1：$s_2$ 的稳健版是秩 $r=4\sim8$ 子空间而非单轴。** 偏好纪元会切换（冗长偏好 → 简洁偏好），届时个别子方向符号翻转。对策：检测用**到人类先验的子空间距离**（符号不变量），归因才用带符号方向。这同时是对整条讨论线最早那个问题的最终回答——表达力的正确形态既非 1 维也非满维，而是这个低秩子空间，且其秩由偏好结构的本征维度决定。
（v0.1 实现：`model.s2_rank` 参数已就位，默认 1；升秩时训练侧自动切换到"向量差的 L2 范数"铰链。）
> **⚠️ 2026-09-25 修订**：多方向不是"稳健版选项"而是**理论必需**——参照模型对换一个，位移读数
> 近乎正交（E5：0.13）；任何单一全局方向无法对齐多家族（E2：四种监督配置读出与真实 $r^*$ 全部反号）。
> 子空间的正确形态待定，候选=①多参照对读数拼接（E6：检测互补有效；细粒度归因仍需监督读出）；
> ②"谱系公共轴 + 族私有残差"分解（与 P1 的残差族指纹 0.98 可分呼应）。
>
> **⚠️ 2026-09-25 晚终版（E8–E11 完整链，已实证；B val 7817 + 同题配对 394×2）**：
> ① **几何**：人机轴与对齐轴在特征空间**不可分**（d_HB 与 d_BI 反向共线 cos −0.91）；

## 附录 B：工程决策记录（与原文的差异及理由）

1. **零初始化只落在一个因子上（修正梯度死锁）**。原文 "α1=α2=0（初始）" + "新通道零初始化"若照字面同时成立，则 $\partial L/\partial w = \alpha(\dots)=0$ 且 $\partial L/\partial \alpha = w\cdot h = 0$——两头都学不动。实现取**固定 α=1、零初始化 $w_1/w_2$**：起点 $s_1\equiv s_2\equiv 0$（起点等价性可自检，见 `scripts/selfcheck.py`），且首步 $w$ 即有非零梯度。u-det 的门控用 `bias=-1` 制造非零起点，属同类问题的另一种解法。
2. **正交正则用归一化 $\cos^2$**：裸内积 $(w_1^\top w_2)^2$ 可被模长缩放规避、对量纲敏感；$\cos^2$ 是"方向正交"的直接度量。零向量处值与梯度均为 0（无 NaN）。
3. **$s_2$ 低秩的落地**：`model.s2_rank = r`，$w_2$ 形状 $(D, r)$；$r=1$ 时即原文标量公式，$r>1$ 时训练用 $\|s_2(x_+)-s_2(x_-)\|_2$ 做铰链（"到子空间的距离"语义）。首版 $r=1$。
4. **$\lambda_d$（旧维语义保持）v0.1 不启用**：该项的语义是"扩张网络时旧通道输出不变"，前提是存在"旧网络"。d-det 从零训练没有旧维可锚定；配置键保留且**非 0 直接报错**（不静默忽略）。将来从 u-det 迁移主干或引入冻结参照时再实现。
5. **计算语义等价（测试回测）延后**：§5 的硬约束"配对双方通过同一测试"在 v0.1 用**同 prompt 近似**（用户决策：现阶段先写代码、尽量不做测试）。数据 schema 不含 passed 字段；严格档（如用 bigcodebench 自带测试回测筛选）列入后续版本。
6. **首版主干取轻量路线**：编码器（codet5blk）+ 池化 + 双读出，主干按注册表（`models/__init__.py`）可插拔；u-det 的 codec 多尺度主干作为后续对照项。

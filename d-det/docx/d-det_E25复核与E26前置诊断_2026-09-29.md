# d-det：E25 复核与 E26 前置诊断

日期：2026-09-29。依据仓库提交 [2be4eb5](https://github.com/EndPB/u-det/commit/2be4eb5) 的 E25 报告及 stage0、investigate、stage1 脚本。本文件独立说明下一步；当前**不启动 E25 阶段 1**。

## 一、先固定真实结论

- E25 阶段 0 门控失败：验证集家族 balanced accuracy，raw mean + DiscHead 为 **.4225**，E24 全 \(z\in\mathbb R^{1537}\) + DiscHead 为 **.4109**。按预先规则暂停新训练是正确执行。
- 已见家族的新模型 test_seen：raw mean + logistic 的家族 balanced accuracy **.2855**，全 \(z\) + logistic **.2263**；检测 AUROC 分别 **.9721**、**.9747**。不能把检测的微小提高说成家族归因也提高。
- 修复了检测先验的训练/推断一致性（同输入差 \(9.54\times10^{-7}\)）；固定编码器输出置换 token 行的差为 \(7.63\times10^{-6}\)。以 unseen 为正类的拒识 AUROC 必须用 \(-\max p_F\)：E24 能量头 **.4120**，B1 逻辑回归头 **.4294**，均没有可用拒识能力。
- 数据是 8 个**实验室家族**，包含多种模型、尺寸和 base/instruct 条件；不能整体称为“8 个旗舰模型”，更不能从这组比较识别纯后训练效应。

## 二、E24 的 \(s_{\mathrm{top}}\) 结果存在结构性零梯度

E24 的 SetPool（flagship_round1.py）把 \(w_q\in\mathbb R^{768}\)、\(b_q\in\mathbb R\) **同时初始化为零**：
\[
q_i=w_q^\top\tilde h_i+b_q=0,\qquad
s_{\mathrm{top}}=\frac1K\sum_{i\in\mathrm{TopK}(q)}q_i=0.
\]
因此训练折每一类在 \(z=[\mu_{768};\log(v+\epsilon)_{768};s_{\mathrm{top},1}]\) 的最后一维都有同一个中心 \(0\)、收缩方差 \(\epsilon\)。该维给每个类别能量添加**相同函数**：
\[
G_c(z)=G_c(z_{1:1536})+
\frac12\left(\frac{s_{\mathrm{top}}^2}{\epsilon}+\log\epsilon\right).
\]
这个公共项在检测能量差与家族 softmax 中抵消。总体均值差 \(\delta\) 的最后一维也为零，因此残差化不会打破对称性。监督对比相似度为归一化内积；所有样本在最后一维为零时，它对该维的一阶导数也为零。所以 E24 的 \(\mathcal L_D,\mathcal L_F,\mathcal L_{\mathrm{SupCon}}^D,\mathcal L_{\mathrm{SupCon}}^F\) 在初始化处均不能给 \(w_q,b_q\) 提供梯度；按当前训练协议，该分量会持续停在零点。

**验证指令（不重训）**：服务端读取 E24 head.pt，输出 wq.weight 的范数、wq.bias、train/val 的 \(s_{\mathrm{top}}\) 最小值/最大值/标准差；再在固定训练 batch 上用 E24 全损失做一次 forward/backward，分别输出 wq.weight 与 wq.bias 的梯度范数，并检查整条 loss 是否数值有效。若为零，E25 报告“\(s_{\mathrm{top}}\) AUROC .5000”只说明**没有学到该分量**，不能得出“关键 token 证据无效”的结论。均值和方差段的比较不受此零梯度结论直接推翻。

E25 未执行的 stage1.py 也沿用零初始化，但用随机线性判别头可打破损失对 \(s_{\mathrm{top}}\) 的对称性；同时它把初始化处零方差维的标准差下限设为 \(10^{-6}\)。如果将来运行，第一步对这一维可能被放大约 \(10^6\) 倍。先记录各维尺度与梯度；安全的最小选项是该臂暂时使用 **768 维 \(\mu\)**、不包含这一维，再另做非零初始化且预定尺度的显著位置实验。不要直接放宽门控启动现有 stage1.py。

## 三、修正 E25 报告中的解释边界

1. “\(\log v\) / \(s_{\mathrm{top}}\) 反稀释”应改成：“E24 固定表示下，给定固定正则和训练样本，全 \(z\) 的线性探针不如 \(\mu\) 单用。”\(s_{\mathrm{top}}\) 实际没有被训练；拼接 768 个方差特征会改变维度与正则有效强度，也不能据一次探针判断二阶信息本质无用。建议补固定特征的正则敏感性/训练内交叉验证诊断，test_seen 不参与选择。
2. “\(r_F\) 的检测坍缩在数学上必然”过强。投影让训练总体 **AI–Human 均值位移**归零，但类条件方差或多模态分布仍可能留下检测信息。E25 在 \(r_F\) 上重新拟合线性逻辑回归得到 val AUROC .5503，才是可报告的经验负结果；不要把将原始 \(z\) 的能量中心直接用于 \(r_F\) 的测试当作有效对照。
3. “base 型召回 0 与后训练假说一致”只能作为线索。base 与 instruct 的规模、模型版本、任务和数量也不同；没有同底座配对不能确认奖励优化造成了差异。“新 generator 的家族差异导致 val→test 跌落”同样是合理解释，尚未排除语言、长度和题目构成变化。
4. E25 报告中 unseen 按来源 split 的样本数出现两组互相矛盾的数：**1200/971/38** 与 **1200/945/64**（两组都合计 2209）。以 meta.json 为准核对并更正报告，保留原值与更正记录。
5. 报告称“只有 ids、无法近重复审计”，但仓库的 semeval_prepare_big.py 从原始 SemEval parquet 的 **code** 列生成 ids，服务器可能仍有原始文件。先查原始 parquet 是否在服务器；若存在，用生成流程的行映射或再分词将已采样 ids 映射回代码后做近重复检查。不要假定原始代码不存在。

## 四、E26 前置诊断的交付与决策

在不生成新样本、不训练新模型的条件下交付一个 E25 勘误/诊断 JSON 与简短报告：

- E24 显著位置头参数、\(s_{\mathrm{top}}\) 分布和一次反向梯度；最后一维训练统计量；
- \(\mu\) 与 \(\mu+\log v\) 的家族探针，使用**训练内**预定的小型正则网格和同一个 val 比较，保存每个设置；不再读取 test_seen 调参；
- unseen 三个来源 split 的准确样本数，原始 parquet 可用性与跨 split 近重复审计；
- 关于旗舰/强模型子集的**逐 generator** 名单、样本数与纳入标准。

若确认零梯度，就把 E24/E25 的结论明确限定为“mean + log variance 的现有表示实验”；单独为显著 token 证据设计可训练的非零起点和正确尺度，再申请最多 2 epoch 的**单变量实验**。若 \(\mu\) 仍无法可靠超过 raw mean，维持 B0 主基线，优先解决生成器、任务与后训练因素的混杂，而不是继续堆流形项。

本文件的理论口径仍是输出分布的精确恒等式
\[
\log(P_f/P_H)=\log(P_{AI}/P_H)+\log(P_f/P_{AI}),
\]
其中当前数据只能估计边缘表示的判别后验；DCAN 的来源无关语义/来源特定风格分离与 DMHM 的密度感知流形分别是参考，不提供“单方向投影”或“对角能量必优”的保证。[DCAN](https://arxiv.org/abs/2603.04212)；[DMHM](https://aclanthology.org/2026.acl-long.180/)。
